# ILY Shop — GitHub Pages starter

เว็บหน้าร้านไอเทมเกม ธีมมินิมอลครีม ประกอบด้วย `index.html` (หน้าร้าน) และ `admin.html` (หน้าจัดการแบบทดลอง)

## เปิดดูในเครื่อง
เปิด `index.html` ในเบราว์เซอร์ได้เลย หรือใช้ VS Code Live Server

## เผยแพร่ด้วย GitHub Pages
1. สร้าง GitHub repository ใหม่
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไว้ที่ root ของ repository
3. ไปที่ **Settings → Pages**
4. เลือก **Deploy from a branch** → `main` → `/ (root)` → Save
5. รอ GitHub สร้างเว็บไซต์ แล้วเปิด URL ที่แสดงในหน้า Pages

## สำคัญก่อนเปิดรับออเดอร์จริง
เวอร์ชันเริ่มต้นนี้เป็น frontend demo ใช้ `localStorage` เท่านั้น:
- ออเดอร์จะอยู่เฉพาะเบราว์เซอร์/อุปกรณ์ที่ลูกค้าสั่ง ไม่ถูกส่งไปหาแอดมิน
- สินค้าและสถานะออเดอร์ไม่ซิงก์ข้ามอุปกรณ์
- หน้าแอดมินยังไม่มีระบบล็อกอินที่ปลอดภัย
- ยังไม่มีการตรวจสอบสลิปหรือรับชำระเงินอัตโนมัติ

GitHub Pages เป็น static hosting จึงต้องเชื่อม backend เช่น Supabase หรือ Firebase เพื่อให้ลูกค้าทุกคนส่งออเดอร์เข้าฐานข้อมูลเดียวกัน และให้เจ้าของร้านเข้าระบบแอดมินอย่างปลอดภัย ห้ามใส่ service-role key หรือรหัสลับไว้ในไฟล์หน้าเว็บ

## ปรับสินค้า
หน้าแอดมินมีฟอร์มเพิ่ม/ลบสินค้าและปรับสถานะออเดอร์สำหรับทดสอบ ข้อมูลตัวอย่างใน `app.js` และ `admin.js` แก้ไขได้ตามต้องการ

## ก่อนใช้งานจริง
ใส่ชื่อสินค้า ราคา เงื่อนไขการส่งมอบ ช่องทางติดต่อ และข้อมูลรับชำระเงินที่ถูกต้องก่อนเผยแพร่ อย่าเผยแพร่ข้อมูลบัญชีหรือข้อมูลส่วนตัวโดยไม่ตรวจสอบ
